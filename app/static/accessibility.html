Accessibility Statement

Target Standard: Web Content Accessibility Guidelines (WCAG) 2.2 Level AA

Last Updated: November 2026

Conformance Status

SaansPlan is engineered to adhere to WCAG 2.2 Level AA. Every interactive component, form control, and content visualization is built using semantic HTML5, explicit ARIA attributes, and accessible color contrast.

Accessibility Measures Implemented

  • WCAG 1.4.3 & 1.4.11 (Contrast): All text elements achieve at least 4.5:1 contrast against their backgrounds (and 3:1 for user interface components and graphical objects).
  • WCAG 1.4.10 (Reflow): The entire interface reflows smoothly without loss of information down to 320 px width without requiring two-dimensional scrolling.
  • WCAG 1.4.12 (Text Spacing): Evaluated against line-height (1.5x), paragraph spacing (2x), letter spacing (0.12x), and word spacing (0.16x) with zero clipping or text overflow.
  • WCAG 2.1.1 & 2.1.2 (Keyboard Navigation): All interactive features are operable via standard keyboard (Tab, Shift+Tab, Enter, Space, Escape) with no keyboard traps.
  • WCAG 2.4.7 & 2.4.11 (Focus Indicator & Obscuration): High-visibility 3px focus rings are enforced on all controls. scroll-padding-top prevents focus from being obscured by sticky headers.
  • WCAG 3.3.1 & 3.3.3 (Error Identification & Suggestion): Form submission errors are aggregated in an ARIA-alert error summary with direct skip links to invalid fields.
  • WCAG 4.1.3 (Status Messages): Dynamic calculations, routine optimizations, and assistant responses announce their completion via polite ARIA live regions.

Technical Verification & Audit Methodology

Accessibility is verified continuously using automated test suites:

  • Axe-Core Automated Scans: Zero violations across initial empty states, loaded results, and active assistant queries.
  • Static Markup Checks: Hermetic Pytest checks validating unique IDs, landmark regions, button labels, and input labels.
  • Internationalization Checks: Native Node.js tests ensuring 100% key parity and Devanagari script integrity across Hindi and English.

Known Limitations & Honest Disclosure

While automated verification with Axe-Core and Playwright confirms 0 violations against WCAG 2.2 AA rules, no formal testing with human users who rely on assistive technologies (such as JAWS, NVDA, or VoiceOver) has been conducted to date.

Hourly smog forecast charts are accompanied by tabular summaries, but complex multi-pollutant visual graphs may require further screen reader optimization.
